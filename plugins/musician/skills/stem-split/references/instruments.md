# 악기 이름과 demucs 대응표

사용자가 말한 악기를 `stem.py run` 의 `--stem` 값으로 바꿀 때 이 표를 쓴다. 표에 없는 악기는 분리할 수 없다.

## 1. 악기 대응

| 사용자 표현 | `--stem` | 모델 | 품질 |
| --- | --- | --- | --- |
| 보컬, 목소리, 노래, 가사, 랩, 코러스 | `vocals` | htdemucs | 좋음. 코러스와 메인 보컬은 나뉘지 않는다 |
| 드럼, 퍼커션, 비트 | `drums` | htdemucs | 좋음 |
| 베이스, 베이스 기타, 신스 베이스 | `bass` | htdemucs | 좋음 |
| 기타, 일렉 기타, 어쿠스틱 기타 | `guitar` | htdemucs_6s | 보통. 다른 악기가 조금 섞인다 |
| 피아노, 건반, 키보드 | `piano` | htdemucs_6s | 약함. 번짐과 잡음이 많다 |
| 나머지 전부, 그 외 | `other` | htdemucs | 보컬, 드럼, 베이스를 뺀 모든 소리가 섞여 있다 |

- 기타와 피아노가 하나라도 있으면 6 stem 모델(htdemucs_6s)을 쓴다. 이 모델의 `other` 에는 기타와 피아노가 빠진다.
- 신스, 스트링, 바이올린, 관악기, 오르간처럼 표에 없는 악기는 따로 뽑을 수 없다. `other` 에 섞여 나온다는 점을 알리고 `other` 를 받을지 묻는다.
- 일렉 기타와 어쿠스틱 기타, 리드와 리듬 기타처럼 같은 악기 안에서 더 나누는 것은 안 된다.

## 2. 빼기 요청

특정 악기를 뺀 연습용 음원은 `--minus` 로 만든다. 결과 파일 이름은 `no_<악기>` 다.

| 사용자 표현 | 명령 |
| --- | --- |
| MR, 반주만, 보컬 제거, 노래방 | `--stem vocals --minus` |
| 드럼 빼고, 드럼 연습용 | `--stem drums --minus` |
| 베이스 빼고, 베이스 연습용 | `--stem bass --minus` |
| 기타 빼고, 기타 연습용 | `--stem guitar --minus` (6 stem 모델) |

뺀 악기 쪽 소리가 조금 남거나 다른 악기가 조금 같이 빠질 수 있다.

## 3. 모델

| 모델 | 악기 | 속도 | 쓰는 경우 |
| --- | --- | --- | --- |
| htdemucs | vocals, drums, bass, other | 빠름 | 기본 |
| htdemucs_ft | 위와 같음 | htdemucs 의 4배쯤 | `--quality high`. 결과가 조금 더 깨끗하다 |
| htdemucs_6s | 위 넷 + guitar, piano | htdemucs 와 비슷 | 기타나 피아노 요청 |

장치는 demucs 가 cuda, mps(Apple Silicon), cpu 순서로 고른다. CPU 만 있으면 곡 길이의 1.5배쯤 걸린다. 처음 쓰는 모델은 실행할 때 내려받는다.
